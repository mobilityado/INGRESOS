## Instalación

1. Sustituye `Code.gs` en Apps Script.
2. Publica una nueva versión.
3. Reemplaza todos los archivos en GitHub.
4. Presiona `Ctrl + F5`.

La URL `/exec` permanece configurada en `config.js`.
